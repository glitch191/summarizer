Settings · Version -

Instruction

Leave this field empty to send only the address of the video, for example when your Gemini settings already say how to summarize a link. Otherwise Gemini receives this text, an empty line, then the address. The default text comes from default-instruction.txt at the root of the extension and is empty.

Behavior

Send the request as soon as the text is in the prompt field. When off, the field is filled and you send it yourself.

Open each new summary in the Gemini popup window that is already open, instead of a new window.

Window

The size and position of the Gemini popup window are saved when you resize or move it.
